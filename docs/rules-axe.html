Landmarks

  • Ensure the document has at most one main landmark (Moderate)
Landmark 2 All content must be contained in landmarks
  • Ensure all page content is contained by landmarks (Moderate)
Landmark 4 banner landmark: identifies branding content
  • Ensure the document has at most one banner landmark (Moderate)
Landmark 5 banner landmark: no more than one
  • Ensure the document has at most one banner landmark (Moderate)
Landmark 6 contentinfo landmark: identifies admin content
  • Ensure the document has at most one contentinfo landmark (Moderate)
Landmark 7 contentinfo landmark: no more than one
  • Ensure the document has at most one contentinfo landmark (Moderate)

  • Ensure the banner landmark is at top level (Moderate)
Landmark 11 main landmark: must be top-level
  • Ensure the main landmark is at top level (Moderate)

  • Ensure the contentinfo landmark is at top level (Moderate)

  • Ensure landmarks are unique (Moderate)

  • Ensure the complementary landmark or aside is at top level (Moderate)

  • Ensure that the page, or at least one of its frames contains a level-one heading (Moderate)
Heading 5 Headings must be properly nested
  • Ensure the order of headings is semantically correct (Moderate)

Color/Content

Rule ID OpenA11y Rule Summary Related aXe Rules
Color 1 Color contrast of text: Minimum
  • Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds (Serious)
Color 3 Color contrast of text: Enhanced
  • Ensure the contrast between foreground and background colors meets WCAG 2 AAA enhanced contrast ratio thresholds (Serious)
Frame 1 frame must have accessible name
  • Ensure <iframe> and <frame> elements have an accessible name (Serious)
Frame 2 iframe must have accessible name
  • Ensure <iframe> and <frame> elements have an accessible name (Serious)
HTML 1 Replace marquee and blink elements
  • Ensure <marquee> elements are not used (Serious)
  • Ensure <blink> elements are not used (Serious)
Language 1 Page must use language code
  • Ensure every HTML document has a lang attribute (Serious)
  • Ensure the lang attribute of the <html> element has a valid value (Serious)
  • Ensure that HTML elements with both valid lang and xml:lang attributes agree on the base language of the page (Moderate)
  • Ensure lang attributes have valid values (Serious)
List 1 Use semantic markup for lists
  • Ensure that lists are structured correctly (Serious)
  • Ensure <li> elements are used semantically (Serious)

Images

Rule ID OpenA11y Rule Summary Related aXe Rules
Image 1 Images must have alt text
  • Ensure <img> elements have alternative text or a role of none or presentation (Critical)
  • Ensure <area> elements of image maps have alternative text (Critical)
  • Ensure [role="img"] elements have alternative text (Serious)
  • Ensure <svg> elements with an img, graphics-document or graphics-symbol role have accessible text (Serious)
  • Ensure <object> elements have alternative text (Serious)

Target Size 1 Author sizing of links (Minimum)

ARIA Widgets

Rule ID OpenA11y Rule Summary Related aXe Rules
Widget 1 Accessible name is required
  • Ensure every ARIA button, link and menuitem has an accessible name (Serious)
  • Ensure every ARIA dialog and alertdialog node has an accessible name (Serious)
  • Ensure every ARIA input field has an accessible name (Serious)
  • Ensure every ARIA meter node has an accessible name (Serious)
  • Ensure every ARIA progressbar node has an accessible name (Serious)
  • Ensure every ARIA treeitem node has an accessible name (Serious)
  • Ensure every ARIA toggle field has an accessible name (Serious)
  • Ensure every ARIA tooltip node has an accessible name (Serious)
Widget 3 role must be valid
  • Ensure elements do not use deprecated roles (Minor)
  • Ensure all elements with a role attribute use a valid value (Critical)
  • Ensure role attribute has an appropriate value for the element (Minor)
Widget 4 Values must be valid
  • Ensure ARIA attributes are used as described in the specification of the element's role (Serious)
  • Ensure all ARIA attributes have valid values (Critical)
Widget 5 Attributes that start with aria- must be defined.
  • Ensure attributes that begin with aria- are valid ARIA attributes (Critical)
Widget 6 Widgets must set properties
  • Ensure ARIA attributes are used as described in the specification of the element's role (Serious)
  • Ensure elements with ARIA roles have all required ARIA attributes (Critical)
Widget 7 Widgets must have owned elements
  • Ensure elements with an ARIA role that require child roles contain them (Critical)
Widget 8 Role must have parent
  • Ensure elements with an ARIA role that require parent roles are contained by them (Critical)
Widget 12 Accessible name is descriptive
  • Ensure ARIA attributes are used as described in the specification of the element's role (Serious)
Widget 14 Unsupported and deprecated ARIA attributes.
  • Ensure an element's role supports its ARIA attributes (Critical)
  • Ensure ARIA attributes are used as described in the specification of the element's role (Serious)
  • Ensure ARIA attributes are not prohibited for an element's role (Serious)
  • Ensure elements do not use deprecated roles (Minor)
Widget 17 aria-braillelabel is more usable
  • Ensure aria-braillelabel and aria-brailleroledescription have a non-braille equivalent (Serious)
Widget 18 aria-brailleroledescription abbreviated role description.
  • Ensure aria-braillelabel and aria-brailleroledescription have a non-braille equivalent (Serious)
